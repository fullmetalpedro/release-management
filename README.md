| `*.png` (raiz) | Logos |

## Rodar a apresentação

```bash
python -m http.server 8765
```

Abrir `http://localhost:8765`. Atalhos: `←` `→` navegar, `P` autoplay, `F` tela cheia, `#N` na URL abre o slide N.
